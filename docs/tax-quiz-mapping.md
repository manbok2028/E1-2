# quiz-game 세금 문항 반영표

`manbok2028/quiz-game`의 `create_default_quizzes()`에 있던 세금 기초 5문항을 E1-2의 `default_data.py`에 옮기고, 기존 E1-2의 저장·힌트·무작위 출제·점수 이력 기능과 결합했다.

| quiz-game의 핵심 주제 | E1-2 반영 위치 | 학습자에게 알려 주는 핵심 |
| --- | --- | --- |
| 국세가 아닌 세금 | 기본 퀴즈 1번 | 재산세는 지방세라는 구분 |
| 종합소득세 원칙상 신고·납부 시기 | 기본 퀴즈 2번 | 원칙상 다음 해 5월 말, 실제 일정은 최신 공지 확인 |
| 급여의 원천징수 | 기본 퀴즈 3번 | 급여를 줄 때 세금을 미리 떼는 제도 |
| 부가가치세 기본 세율 | 기본 퀴즈 4번 | 일반 과세 거래의 기본 세율 학습 |
| 과다 납부 후 경정청구 | 기본 퀴즈 5번 | 많이 낸 세금을 바로잡아 달라고 요청하는 절차 |

## E1-2에서 추가한 안전장치

- 각 문제에 힌트를 붙여 처음 배우는 학습자가 용어를 이해할 수 있게 했다.
- 문제 순서를 무작위로 섞고, 원하는 문제 수만 풀 수 있게 했다.
- 퀴즈·최고 점수·이력을 UTF-8 `state.json`에 저장한다.
- 빈 입력, 문자, 범위 밖 숫자, 파일 손상, Ctrl+C·EOF를 안전하게 처리한다.
- 세법·기한·세율은 바뀔 수 있으므로 실제 신고·납부 판단에 게임 답을 사용하지 않도록 안내했다.

## 공식 확인 경로

- [국세청 종합소득세 개요](https://g.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7664&mi=2224): 원칙상 종합소득세 신고·납부 기간과 예외 안내
- [국세청 세무일정](https://nts.go.kr/nts/ad/taxSchdul/selectList.do?mi=135747&taxMonth=&taxYear=2026): 해당 연도의 실제 일정 확인
- [국세청 부가가치세 개요](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7703&mi=2272): 부가가치세 공식 안내

> 이 표와 퀴즈는 교육용입니다. 실제 신고·납부 전에는 반드시 공식 안내 또는 세무 전문가의 개별 안내를 확인해야 합니다.
