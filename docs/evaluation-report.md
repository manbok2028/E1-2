## 1. 한눈에 보는 결과

| 질문 | 아주 쉽게 말하면 |
| --- | --- |
| 무엇을 만들었나요? | 컴퓨터에게 문제를 내 달라고 부탁하고, 답을 맞히는 터미널 퀴즈 게임입니다. |
| 무엇이 특별한가요? | 퀴즈를 새로 넣고, 프로그램을 껐다 켜도 퀴즈와 최고 점수가 `state.json`에 남습니다. |
| 주제는 무엇인가요? | 한글·무궁화·독도·무지개·태양처럼 우리 문화와 기초 과학을 함께 배웁니다. |
| 왜 이 주제인가요? | 익숙한 소재로 Python의 입력·조건·반복·저장을 쉽게 배우기 위해서입니다. |
| 실행 방법은? | 프로젝트 폴더에서 `python main.py`를 입력합니다. Python 3.10 이상이면 되고 외부 라이브러리는 필요 없습니다. |

## 2. 평가자가 확인할 순서

1. `python main.py`를 실행하고 메뉴에서 1~6을 선택한다.
2. `2. 퀴즈 추가`로 문제를 하나 넣고 종료한 뒤 다시 실행한다. `3. 퀴즈 목록`에서 문제가 남아 있으면 저장 성공이다.
3. 메뉴에 `abc`, 빈 Enter, `9`를 넣어 안내 문구와 재입력 흐름을 확인한다.
4. `python -m unittest discover -s tests -v`를 실행해 6개 핵심 테스트의 통과를 확인한다.
5. `git log --oneline --graph --all`로 기능 단위 커밋과 `feature/play-quiz` 병합을 확인한다.

## 3. 메뉴와 기능

| 메뉴 | 하는 일 | 저장 여부 |
| --- | --- | --- |
| 1. 퀴즈 풀기 | 문제 순서를 섞고, 풀 문제 수를 고른 뒤 채점합니다. `h`는 힌트이며 10점이 줄어듭니다. | 점수·게임 이력 저장 |
| 2. 퀴즈 추가 | 문제, 선택지 4개, 정답 번호, 힌트를 입력합니다. | 새 퀴즈 저장 |
| 3. 퀴즈 목록 | 등록된 문제 제목과 개수를 보여 줍니다. | 읽기만 함 |
| 4. 점수 확인 | 최고 점수와 가장 최근 결과를 보여 줍니다. | 읽기만 함 |
| 5. 퀴즈 삭제 | 번호를 골라 퀴즈를 삭제합니다. (보너스) | 변경 내용 저장 |
| 6. 종료 | 마지막 상태를 저장하고 안전하게 끝냅니다. | 저장 |

## 4. 과제 목표를 코드로 설명하기

### Python 기초

| 배운 것 | 어린 학생에게 설명하면 | 코드 속 예 |
| --- | --- | --- |
| 변수 | 값을 담는 이름표가 붙은 상자입니다. | `best_score` 상자에는 가장 높은 점수를, `question` 상자에는 문제 글을 넣습니다. |
| `int` | 1, 2, 100처럼 셀 수 있는 숫자입니다. | `answer=1`, `best_score=100` |
| `str` | 글자 상자입니다. | `"한글을 만든 왕은?"` |
| `bool` | “맞아/아니야”만 담는 스위치입니다. | `quiz.is_correct()`가 정답이면 `True`를 돌려줍니다. |
| `list` | 여러 물건을 순서대로 담는 바구니입니다. | 선택지 4개와 퀴즈 목록 |
| `dict` | 이름표와 값을 짝지어 넣는 서랍입니다. | JSON의 `question`, `choices`, `answer` |
| `if/elif/else` | “만약 그렇다면 이쪽, 아니면 저쪽” 갈림길입니다. | 정답이면 `✅`, 오답이면 정답 번호를 보여 줍니다. |
| `while` | 조건이 맞는 동안 계속 되풀이합니다. | 잘못 입력하면 올바른 숫자가 나올 때까지 다시 묻습니다. |
| `for` | 바구니의 물건을 하나씩 꺼냅니다. | 퀴즈 목록과 선택지를 차례로 출력합니다. |
| 함수·매개변수·반환값 | 자주 쓰는 일을 이름 붙인 작은 기계입니다. | `ask_number(prompt, minimum, maximum)`은 질문과 범위를 받아 올바른 숫자를 돌려줍니다. |

### 클래스와 객체

클래스는 “쿠키 틀”, 객체는 “그 틀로 만든 쿠키 한 개”라고 생각하면 쉽습니다.

| 코드 | 역할 |
| --- | --- |
| `Quiz` 클래스 | 문제 하나를 만드는 틀입니다. 문제·선택지·정답·힌트를 가진 퀴즈 객체를 만듭니다. |
| `QuizGame` 클래스 | 여러 문제와 점수, 메뉴를 관리하는 게임 진행자입니다. |
| `__init__` | 새 게임을 시작할 때 퀴즈·점수·파일 경로를 처음 준비합니다. |
| `self` | “지금 이 게임 자신”을 가리킵니다. `self.quizzes`는 이 게임의 퀴즈 바구니입니다. |
| 속성·메서드 | 속성은 가진 것(`quizzes`, `best_score`), 메서드는 할 수 있는 일(`play_quizzes`, `save`, `add_quiz`)입니다. |

### 파일 입출력과 오류 처리

`state.json`은 게임의 **기억 공책**입니다. UTF-8로 열고 쓰므로 한글 문제도 남습니다.

```json
{
  "quizzes": [{"question": "...", "choices": ["..."], "answer": 1, "hint": "..."}],
  "best_score": 100,
  "history": [{"played_at": "날짜", "score": 100}]
}
```

- 파일이 없으면 기본 6문제로 시작합니다.
- JSON이 망가지거나 읽지 못하면 `try/except`가 프로그램이 멈추는 일을 막고 기본 문제로 복구합니다.
- `Ctrl+C` 또는 입력 끝(EOF)이 발생해도 `finally`에서 가능한 데이터를 저장하고 안전하게 종료합니다.

### Git 기초

| 명령 | 쉬운 설명 | 이 과제의 근거 |
| --- | --- | --- |
| `git init` | 새 변화 기록 공책을 시작합니다. | E1-2 로컬 저장소 생성 |

| `git commit` | “여기까지 만들었다”는 날짜 도장입니다. | 메뉴, Quiz, 저장, 플레이, 테스트, 문서 등 10개 이상 |

| `git push` | 내 컴퓨터 공책을 GitHub에도 올립니다. | 제출 시 `origin/main`으로 푸시 |
| `git clone` | GitHub 공책을 다른 폴더에 복사합니다. | `quiz-evidence-clone` 폴더에 실제 복제 완료 |
