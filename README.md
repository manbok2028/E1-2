# E1-2 · 우리 문화 퀴즈 게임

Python으로 만든 터미널 퀴즈 게임입니다. 프로그램을 껐다 켜도 퀴즈와 최고 점수가 `state.json`에 남습니다.

> 상세한 제출 설명은 [평가 보고서](docs/evaluation-report.md)에서 확인할 수 있습니다.

## 실행 예정

```powershell
python main.py
```

## 개발 약속

- Python 표준 라이브러리만 사용합니다.
- 데이터는 프로젝트 루트의 UTF-8 `state.json`에 저장합니다.
- 기능별로 작은 메서드와 클래스를 나눠 작성합니다.
